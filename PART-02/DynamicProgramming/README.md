## 08. 다이나믹 프로그래밍

### 다이나믹 프로그래밍이란?

다이나믹 프로그래밍은 복잡한 문제를 작은 하위 문제로 나누어 풀고, 이 하위 문제들의 해답을 저장하여 중복 계산을 피하는 효율적인 알고리즘 설계 기법이다.

### 탑다운 방식, 보텀업 방식

- 탑다운(Top-down) 방식: "하향식"이라고도 불리며, 큰 문제에서 시작해 필요한 작은 하위 문제들을 재귀적으로 호출하며 해결한다.
- 보텀업(Bottom-up) 방식: "상향식"이라고도 불리며, 가장 작은 하위 문제들부터 시작하여 차례대로 해답을 구하고, 이 해답들을 이용하여 점차적으로 더 큰 문제의 해답을 구성해 나간다.

### 피보나치 수열 (대표적인 예시)
![피보나치 수열](https://github.com/user-attachments/assets/d953e0ee-be36-4dec-a715-1ec3a4d5fea6)

피보나치 수열은 f(n) = f(n-1) + f(n-2) 와 같이 이전 두 항의 합으로 정의된다. 다이나믹 프로그래밍을 사용하지 않으면, f(6)을 구하기 위해 f(5)와 f(4)를 계산해야 하고, f(5)를 위해 다시 f(4)와 f(3)을, f(4)를 위해 f(3)과 f(2)를 계산하는 식으로 f(4)나 f(3) 같은 값들이 여러 번 중복해서 계산된다.

하지만 예를 들어, 다이나믹 프로그래밍의 보텀업 방식을 사용하면, f(0)부터 차례대로 f(1), f(2), f(3), f(4), f(5)의 값들을 미리 계산해서 저장해둔다. 이렇게 저장된 값들이 있으니, f(6)을 계산할 때 f(5)와 f(4)를 다시 계산할 필요 없이 이미 저장되어 있는 값을 가져다 사용하여 효율적으로 답을 구할 수 있다.
